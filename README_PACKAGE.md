# YiYi Codex Starter Package

This package contains:

- `YIYI_MASTER_DEVELOPMENT_SPEC.md` — complete frozen product and engineering specification.
- `AGENTS.md` — persistent repository instructions for Codex.
- `CODEX_KICKOFF_PROMPT.md` — first prompt for Phase 0.
- `TECHNICAL_VERIFICATION_NOTES.md` — concise record of corrected technical decisions.

Place these files in the new YiYi repository root. Keep the UI images in the repository folder named `参考图/`.
